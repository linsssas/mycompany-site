# Invomat — маркетинг: SEO, контент, каналы

## SEO

Страница `/invoice` уже оптимизирована: заголовок и описание под ключевые
запросы, FAQ-блок с фразами из семантики, sitemap.xml и robots.txt.

### Семантическое ядро (стартовое)

| Кластер | Запросы | Носитель |
|---|---|---|
| Инструмент | «генератор инвойсов», «инвойс онлайн бесплатно» | страница /invoice ✅ |
| Upwork/фриланс | «инвойс для upwork», «как выставить инвойс фрилансеру» | статья (план, №1) |
| ВЭД/валюта | «как выставить счёт иностранной компании», «инвойс для валютного контроля» | статья (план, №2) |
| Образцы | «инвойс образец на английском», «invoice template на русском» | статья + примеры (план, №3) |
| Реквизиты | «что такое SWIFT и IBAN», «реквизиты для получения валюты» | статья (план, №4) |

План: 2 статьи/мес, пишет ИИ, владелец мержит PR. Каждая статья заканчивается
СТА «создайте инвойс за 2 минуты».

## Бесплатные каналы (до первых денег)

1. **Телеграм-чаты фрилансеров** СНГ (фриланс, релокация, Upwork) — ответы на
   вопросы «как выставить инвойс» со ссылкой; только по делу, без спама.
2. **VC.ru / Хабр / vc-эквиваленты КЗ** — 1 статья «Как фрилансеру выставить
   инвойс зарубежному клиенту (и получить оплату)» с инструментом внутри.
3. **Reddit/HN не подходят** до английской версии; после — r/freelance, Product Hunt.
4. **YouTube Shorts/TikTok** (опционально): 30-секундные «инвойс за 2 минуты» —
   ИИ готовит сценарии, если владелец захочет канал.

## Платные каналы

Только после базового органического потока: Яндекс.Директ по «инвойс
генератор» (низкий CPC), тест $50. До этого — не тратить.

## Сообщения бренда

- Главное: «Инвойс для зарубежного заказчика — за 2 минуты. Бесплатно».
- Приватность: «данные не покидают ваш браузер» — важно для финансовых данных.
- Для Pro: «уберите чужой бренд из документа, который видит ваш клиент».

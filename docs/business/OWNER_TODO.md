# Действия владельца (только то, что нельзя сделать без вас)

## Для запуска (≈15 минут)

1. **Смержить PR #4** в `main` — GitHub Actions задеплоит сайт автоматически
   (Settings → Pages → Source: GitHub Actions должен быть включён).
2. **Проверить продукт**: https://linsssas.github.io/mycompany-site/invoice —
   заполнить тестовый инвойс, нажать «Скачать PDF / Печать».
3. Калькулятор СЭС на главной не изменён — можно убедиться.

## Первые деньги (≈1 час, по одному разу)

4. **Сгенерировать себе пачку Pro-ключей**: `node scripts/generate-license.mjs 20`
   (локально или попросите меня — я выведу ключи в чат). Храните список у себя;
   по одному выдаёте каждому покупателю.
5. **Завести Gumroad** (проще всего): продукт «Invomat Pro» за $10 с полем
   «ключ выдаётся в течение часа» — либо сразу вставить ключ в автоответ
   Gumroad. Прислать мне ссылку — я добавлю кнопку «Купить» на страницу.
6. **Google Search Console + Яндекс.Вебмастер**: подтвердить сайт, отправить
   sitemap.xml.
7. Заявки на Pro приходят на linar.caser@gmail.com — отвечать ключом после
   оплаты (пока не подключён Gumroad-автоответ).

## По мере роста

8. Купить домен (например, invomat.com / invomat.io — проверить свободность
   и товарные знаки; запасные: invofast, schetnow) и привязать к Pages —
   после этого скажите мне, я обновлю конфигурацию и sitemap.
9. Счётчик аналитики (GA4/Plausible) — создать, прислать ID.
10. Разместить 1 статью на VC.ru от вашего имени (текст подготовлю я).

## Решаем вместе

- Цена Pro ($7/$10/$15 — тестируем).
- Момент выхода английской версии.
- Судьба калькулятора СЭС: он остаётся на главной как есть; захотите
  продвигать или продать как отдельный актив — обсудим.

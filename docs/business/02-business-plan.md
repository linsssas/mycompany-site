# Invomat — бизнес-план

## Продукт

Бесплатный онлайн-генератор инвойсов для фрилансеров и микробизнеса СНГ,
работающих с зарубежными заказчиками. Живёт на `/invoice` этого сайта
(калькулятор СЭС остаётся нетронутым на главной; при покупке домена продукт
переедет на собственный адрес).

Возможности v1 (реализовано):
- инвойс на английском или русском (переключение в один клик);
- любые валюты (ISO-код), формат сумм по локали;
- позиции с количеством и ценой, скидка %, налог %;
- платёжные реквизиты (IBAN/SWIFT/банк) и ИИН/БИН/ИНН;
- живой предпросмотр А4 и сохранение в PDF (печать браузера — идеальная
  вёрстка и кириллица без проблем со шрифтами);
- автосохранение данных в браузере (localStorage), приватность: данные не
  покидают устройство;
- Pro-разблокировка ключом: убирает строку «Создано в Invomat» из PDF.

## Аудитория

1. Фрилансеры СНГ с прямыми зарубежными контрактами (разработка, дизайн,
   маркетинг) — инвойс нужен каждому платежу.
2. Самозанятые/ИП, продающие услуги за валюту (валютный контроль банка).
3. Микроагентства (2–5 человек) без бухгалтерии.

## Монетизация

| Уровень | Цена | Что даёт |
|---|---|---|
| Free | 0 | Все функции, строка «Создано в Invomat» в PDF |
| Pro (v1) | 4 990 ₸ / ~$10 разово | Без брендинга, навсегда |
| Pro+ (этап 2) | ~$3–5/мес | Шаблоны актов и договоров RU/EN, нумерация, несколько профилей |

Механика v1: покупатель платит (Gumroad/Lemon Squeezy или перевод) → получает
ключ формата `IVM-XXXX-XXXX` (генератор: `scripts/generate-license.mjs`) →
вводит на сайте. Проверка ключа локальная (контрольная сумма) — честный
компромисс для статического сайта; при появлении бэкенда (Supabase) заменяется
на серверную проверку с привязкой к покупке.

## Архитектура

- Сейчас: Next.js static export, GitHub Pages, ноль затрат. Код продукта:
  `src/app/invoice/`, `src/components/invoice/`, `src/lib/invoice/`.
- Этап 2: собственный домен, Supabase (ключи, синхронизация профилей),
  вебхук платёжного провайдера → автоотправка ключа письмом.

## Дорожная карта

- КВ1: платёжная ссылка Gumroad; 3 SEO-статьи; счётчик аналитики.
- КВ2: шаблоны «Акт выполненных работ» и «Договор оказания услуг» RU/EN (Pro+);
  автонумерация инвойсов; несколько сохранённых профилей.
- КВ3: английская версия интерфейса (выход на глобальный рынок «freelancer
  invoice generator» — конкурентнее, но рынок х100); экспорт в .docx.
- КВ4: Telegram-бот «инвойс из чата» как второй канал (та же кодовая база расчёта).

## Риски

| Риск | Контрмера |
|---|---|
| Бесплатные конкуренты | Локализация СНГ (RU/EN, IBAN/SWIFT, ИИН/БИН) — их слепая зона |
| Низкий чек | Этап 2 — Pro+ подписка с документами; объём через SEO |
| Обход локальной проверки ключа | Принять как издержку v1 (платят за удобство и поддержку), серверная проверка на этапе 2 |
| Правовые нюансы форм документов | Дисклеймер «не является налоговой/юридической консультацией» (уже на странице) |

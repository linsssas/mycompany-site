# Invomat — финансовая модель

Цифры — план для решений, не гарантия. Курс: 1 USD ≈ 500 ₸.

## Затраты

| Статья | Сейчас | С ростом |
|---|---|---|
| Хостинг (GitHub Pages) | 0 | 0 |
| Домен | 0 | ~$10/год |
| Платёжный провайдер | 0 фикс | ~10% с транзакции (Gumroad) или 5%+$0.50 (Lemon Squeezy) |
| Аналитика / рассылка | 0 (GA4, Brevo free) | 0–$9/мес |
| **Итого фикс.** | **0** | **≈$1–2/мес** |

Безубыточность: **2 продажи Pro в год** покрывают всё.

## Юнит-экономика

- Pro $10 разово → ~$9 маржи с продажи (после комиссии провайдера).
- CAC ≈ 0 (органический SEO + бесплатные каналы).
- Этап 2 Pro+ $4/мес → LTV при churn 10%/мес ≈ $40.

## Сценарии (через 6 месяцев SEO)

| Показатель | Пессимистичный | Базовый | Оптимистичный |
|---|---|---|---|
| Посетители/мес | 500 | 2 000 | 8 000 |
| Создали инвойс | 40% | 50% | 60% |
| Конверсия в Pro | 0.5% | 1% | 2% |
| Продаж Pro/мес | 1 | 10 | 90+ |
| **Доход/мес** | **~$10** | **~$100** | **~$900+** |

Рычаги роста дохода по порядку значимости:
1. **Трафик** — SEO-статьи под запросы «инвойс для upwork», «счёт иностранной
   компании», «invoice образец» (конкуренция в выдаче — статьи банков, не инструменты).
2. **Конверсия Free→Pro** — брендинг в PDF виден получателю-заказчику, это
   встроенный мотиватор; тест цены $7/$10/$15.
3. **Средний чек** — Pro+ подписка (акты, договоры) на этапе 2.
4. **Второй рынок** — английский интерфейс: глобальный трафик на порядок больше.

## Вехи

- Первая продажа → подтверждение спроса, подключить Gumroad (автовыдача ключей).
- $100/мес → вложиться в английскую версию.
- $300/мес → Supabase + серверные лицензии + Pro+ подписка.

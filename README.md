# Калькулятор металлоконструкций опор СЭС

Инженерный веб-калькулятор для расчета снеговых, ветровых и постоянных нагрузок на
металлоконструкции опор солнечных электростанций (СЭС) произвольной конфигурации.
Построен на Next.js + TypeScript + Tailwind CSS + Zustand + three.js (react-three-fiber).

## Возможности (MVP)

- Полностью параметрическая геометрия (длина/ширина/высота, стойки, пролеты, балки,
  прогоны, подкосы, связи, свесы, раскладка панелей) с автоматическим пересчетом при
  изменении любого параметра.
- Библиотека солнечных панелей и стальных профилей (трубы, швеллеры, уголки, двутавры)
  либо ручной ввод размеров сечения.
- Марки стали S235/S275/S355/C245/C255/C345.
- База климат-районов (снег/ветер) по областям и городам Казахстана, либо ввод GPS.
- Расчет снеговой нагрузки, ветровой нагрузки (6 направлений, включая ветер снизу/сверху),
  собственного веса, усилий в элементах (N/M/V), проверок прочности/устойчивости/местной
  устойчивости с цветовой индикацией (🟢/🟡/🔴), проверки анкеров и фундамента.
- Комбинации нагрузок G, G+S, G+W, G+S+W, ULS, SLS с определением наиболее опасной.
- 3D-модель конструкции (вращение мышью) и параметрические 2D-чертежи (спереди/сбоку/сверху)
  со спецификацией металла.
- Формирование PDF-отчета по расчету, сохранение/загрузка проекта в JSON.


## Калькулятор опоры солнечных панелей (`/tools/solar-support`)

Отдельный, более строгий инструмент: параметрический расчёт снеговой и ветровой
нагрузки на опору солнечных панелей с проверками по еврокодовой базе.

### Что считает

- **Снег** — СП РК EN 1991-1-3: `s = μ₁·Ce·Ct·sk`, схемы С1 (равномерно), С2 (половина
  длины стола), С3a/С3b (снег на одном ряду панелей), С4 (скопление у нижней кромки),
  пересчёт на другой период повторяемости, поправка на высоту над уровнем моря.
- **Ветер** — СП РК EN 1991-1-4, п. 7.3 (свободно стоящий навес): профиль скорости,
  `qp(ze)`, схемы прижима и отсоса при φ = 0 и φ = 1, ветер вдоль стола (трение по
  панелям + торцевой силуэт), краевые зоны, эксцентриситет равнодействующей на 0,25·d
  (реализован распределением нагрузки, а не добавочной парой сил). Опционально —
  проверочная ветка ASCE 7-22, гл. 29.4.4 (GCrn).
- **Расчётная схема** — три уровня передачи нагрузки: панель → неразрезной прогон →
  балка → плоская рама. Рама решается МКЭ (3 степени свободы в узле, шарниры,
  упругое защемление стоек в грунте пружинами по глубине заглубления либо жёсткая
  заделка). Выводятся эпюры M, N, Q по любому сочетанию.
- **Сечения** — характеристики холодногнутых профилей (C, Σ, Z, труба, уголок)
  вычисляются по средней линии с поправкой на скругления (EN 1993-1-3, п. 5.1.4);
  центр изгиба и секториальный момент инерции — методом секториальных площадей;
  эффективные характеристики Aeff и Weff — с учётом местной потери устойчивости
  плоских элементов и распорной устойчивости краевых отгибов.
- **Проверки элементов** — EN 1993-1-3: растяжение, сжатие, изгиб, устойчивость
  (кривая b), устойчивость плоской формы изгиба, срез стенки, местная опорная реакция
  (web crippling), совместные действия N+M и M+V, кручение, предельные гибкости,
  прогибы (в том числе допуск производителя модуля).
- **Болтовые узлы** — EN 1993-1-8 и EN 1993-1-3 разд. 8: срез, смятие тонкого листа
  (как правило, определяющая проверка при t = 1,5–2 мм), растяжение, продавливание,
  совместное действие, расстановка болтов; ведомость «требуется / имеется по чертежу».
- **Стойка в грунте** — метод Бромса (несвязный и связный грунт), выдёргивание
  (вес конструкции + бетон + грунт в конусе выпора + трение), вдавливание, морозное
  пучение, подбор потребного заглубления.
- **Сочетания** — EN 1990: 6.10a и 6.10b с каждым ведущим воздействием, отдельное
  сочетание на подъём `0,9·G + 1,5·W(отрыв)`, монтажное сочетание, SLS.

### Вывод

Сводка-светофор с определяющим элементом, таблица нагрузок и формул с подстановкой
чисел, таблица проверок со ссылками на пункты норм, прогибы, узлы, фундамент,
спецификация с экономикой, полная таблица сочетаний, эпюры, 2D-схема рамы, план и вид
сбоку, 3D-модель с тепловой картой загруженности, графики (K от угла, снега, скорости
ветра; предельный снег и предельная скорость ветра; расход металла), экспорт в PDF
(А4 с рамкой и штампом, кириллица), Excel и JSON, печать.

Константы норм вынесены в редактируемые JSON-файлы (`src/data/solar/`) с пометками о
необходимости сверки с официальным текстом действующей редакции норм.

### Тесты

```bash
npm test
```

112 юнит-тестов: сверка МКЭ с формулами сопромата (`qL²/8`, `qL²/2`, `qL²/12`, прогибы
`5qL⁴/384EI` и `qL⁴/8EI`, неразрезная балка, шарниры, равновесие), центр изгиба и `Iw`
швеллера по классическим формулам, коэффициенты норм, сочетания, чувствительность
расчёта и защита от нефизичных исходных данных.

## Важные ограничения текущей версии

Это инженерный **предварительный** расчетный инструмент (грузовые площади / простые
статические схемы), а не полноценный МКЭ-решатель уровня SkyCiv/RFEM/SAP2000. Значения
климатических районов и аэродинамических коэффициентов приведены справочно для
демонстрации методики — перед выпуском рабочей документации необходима верификация
квалифицированным инженером-конструктором и уточнение исходных данных по действующим
нормам (СП РК, Еврокод EN 1991/1993, ASCE 7). Экспорт в DWG/STEP/IFC, полноценная
геотехника и параллельная поддержка нескольких нормативных баз в расчетных формулах —
в планах развития.

## Разработка

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

Основной код расчетного ядра находится в `src/lib/calc/`, состояние проекта — в
`src/store/useProjectStore.ts`, интерфейс — в `src/components/`.

# Калькулятор металлоконструкций опор СЭС

Инженерный веб-калькулятор для расчета снеговых, ветровых и постоянных нагрузок на
металлоконструкции опор солнечных электростанций (СЭС) произвольной конфигурации.
Построен на Next.js + TypeScript + Tailwind CSS + Zustand + three.js (react-three-fiber).

## Возможности (MVP)

- Полностью параметрическая геометрия (длина/ширина/высота, стойки, пролеты, балки,
  прогоны, подкосы, связи, свесы, раскладка панелей) с автоматическим пересчетом при
  изменении любого параметра.
- Библиотека солнечных панелей и стальных профилей (трубы, швеллеры, уголки, двутавры)
  либо ручной ввод размеров сечения.
- Марки стали S235/S275/S355/C245/C255/C345.
- База климат-районов (снег/ветер) по областям и городам Казахстана, либо ввод GPS.
- Расчет снеговой нагрузки, ветровой нагрузки (6 направлений, включая ветер снизу/сверху),
  собственного веса, усилий в элементах (N/M/V), проверок прочности/устойчивости/местной
  устойчивости с цветовой индикацией (🟢/🟡/🔴), проверки анкеров и фундамента.
- Комбинации нагрузок G, G+S, G+W, G+S+W, ULS, SLS с определением наиболее опасной.
- 3D-модель конструкции (вращение мышью) и параметрические 2D-чертежи (спереди/сбоку/сверху)
  со спецификацией металла.
- Формирование PDF-отчета по расчету, сохранение/загрузка проекта в JSON.

## Важные ограничения текущей версии

Это инженерный **предварительный** расчетный инструмент (грузовые площади / простые
статические схемы), а не полноценный МКЭ-решатель уровня SkyCiv/RFEM/SAP2000. Значения
климатических районов и аэродинамических коэффициентов приведены справочно для
демонстрации методики — перед выпуском рабочей документации необходима верификация
квалифицированным инженером-конструктором и уточнение исходных данных по действующим
нормам (СП РК, Еврокод EN 1991/1993, ASCE 7). Экспорт в DWG/STEP/IFC, полноценная
геотехника и параллельная поддержка нескольких нормативных баз в расчетных формулах —
в планах развития.

## Разработка

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

Основной код расчетного ядра находится в `src/lib/calc/`, состояние проекта — в
`src/store/useProjectStore.ts`, интерфейс — в `src/components/`.

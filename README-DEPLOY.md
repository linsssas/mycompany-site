Эта ветка содержит только готовую статическую сборку сайта
(результат `next build` с output: "export"), без исходного кода.

Она предназначена для скачивания на сервер одной командой и раздачи
через nginx/apache — без Node.js и без сборки на месте.

Пересоздаётся автоматически при каждом деплое, историю не хранит.

Собственная реализация в духе Microsoft TRELLIS.2 (image-to-3D). Без GPU это демо работает в mock-режиме и строит модель по загруженному изображению упрощённым процедурным пайплайном — не настоящей диффузионной моделью. Подробности и как включить реальный пайплайн — в README проекта.

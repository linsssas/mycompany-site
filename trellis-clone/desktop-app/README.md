# Forge3D Desktop

Настольное окно: перетащили фото — получили 3D-модель (GLB). Никакой установки
кроме Python и пары pip-пакетов, GPU на вашем компьютере не нужен — вся тяжёлая
генерация выполняется публичным Hugging Face Space
[microsoft/TRELLIS.2](https://huggingface.co/spaces/microsoft/TRELLIS.2) по сети.

## Запуск

```bash
cd trellis-clone/desktop-app
pip install -r requirements.txt
python app.py
```

Откроется окно: перетащите изображение объекта (лучше на прозрачном/простом фоне)
в область загрузки, выберите разрешение (512/1024/1536) и нажмите
«Сгенерировать 3D». Готовый файл `<имя_фото>_3d.glb` сохранится рядом с исходным
фото; кнопка «Показать в папке» откроет её в проводнике/Finder/файловом менеджере.

## Как это работает и какие есть ограничения

Приложение вызывает тот же Gradio API, которым пользуется веб-версия Space
(`/image_to_3d`, затем `/extract_glb` — см. `trellis_client.py`). Так как это
**чужой публичный сервис**, а не ваш собственный бэкенд:

- Генерация может занимать несколько минут — вы становитесь в общую очередь
  вместе со всеми остальными пользователями Space.
- Space может быть временно недоступен, перегружен или ограничивать число
  запросов для анонимных пользователей.
- Если у вас есть аккаунт на Hugging Face, можно передать токен через
  переменную окружения `HF_TOKEN` — это иногда даёт более высокий приоритет
  в очереди:
  ```bash
  HF_TOKEN=hf_xxx python app.py
  ```
- Если Microsoft изменит код Space и имена API-эндпоинтов, вызовы начнут
  падать с ошибкой вида «endpoint not found». В приложении есть кнопка
  «Диагностика API Space» — она печатает актуальный список эндпоинтов Space
  (`client.view_api()`), по которому можно поправить `api_name` в
  `trellis_client.py`.

## Если нужна гарантированная работа без зависимости от чужого сервиса

Этот десктоп-клиент — самый быстрый способ получить *настоящую* генерацию
без своего GPU, но он зависит от доступности стороннего Space. Если нужна
независимость — в `trellis-clone/backend` есть свой сервер с тем же
пайплайном, который можно развернуть на собственном или арендованном GPU
(`FORGE3D_PIPELINE_MODE=real`, см. `../backend/scripts/setup_real_model.sh`
и `../README.md`).

## Устранение неполадок

- **`ModuleNotFoundError: No module named 'tkinter'`** — на Linux tkinter
  иногда ставится отдельно от Python: `sudo apt install python3-tk`
  (Debian/Ubuntu) или аналог для вашего дистрибутива. На Windows/macOS
  установщики python.org уже включают tkinter.
- **Drag-and-drop не работает** — приложение продолжит работать через кнопку
  выбора файла, даже если `tkinterdnd2` не установился на вашей платформе.
- **Зависло на «Этап 1/2»** — это ожидание в очереди Space, а не зависание
  приложения; можно просто подождать.
